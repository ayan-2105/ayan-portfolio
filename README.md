# Shaikh Mohammed Ayan — Portfolio

A responsive editorial-style personal portfolio using a red / black / warm-paper visual identity, CSS 3D depth, halftone portrait treatment, scroll reveals, motion details and mobile navigation.

## Run locally

No build tools or package installation are required. Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy free

1. Create a GitHub repository and upload the contents of this folder (not the parent folder).
2. Sign in to Netlify or Vercel and import the repository.
3. Choose a static deployment: no build command, publish directory `.`.
4. Deploy and add a custom domain later if desired.

## Edit

- Replace `assets/ayan-portrait-editorial.jpg` to update the hero portrait.
- The original uploaded photo is kept as `assets/ayan-original.jpg`.
- `assets/ayan-resume.pdf` is linked by the hero resume button.
- Update `index.html` for copy and project status; `styles.css` controls the visuals; `script.js` handles scroll progress, reveals and mobile navigation.

Project statuses are deliberately conservative. Update them as implementation advances; do not present planned features as shipped.
